# おはなしの しき：1〜6年の文章題

## 同じお話で図をつくる

1〜2年の合併・増加・減少・比較の12問、および同じ型の作問には「このお話を 図にする」が表示されます。同じ文章・数値・単位・数量の名前・未知の場所で、絵→○→テープの導入や図をつくる練習を開けます。「なぜテープ図？」も利用できます。導入の別のお話を見た場合は「もとのお話の図へ」で元に戻れます。

「この図を お話へもどす」で、その時点の図を文章題の画面へ持ち帰れます。入力途中の式・答え・選択肢は維持します。途中の図も持ち帰れるので、持ち帰りだけでは正答や文章題の完了にしません。対応づけ・図の修正・描画練習の確認結果は、文章題の式・答え・理由の判定と区別します。

持ち帰った図はlocalStorageの `word-problem-diagrams-v1` に最大50問分保存します。問題のIDだけでなく数値・未知の場所・文章も区別し、作問の変更前の図が別の問題に混ざるのを防ぎます。既存の学習記録の削除ボタンで、この図の記録も削除します。

2〜3年の「同じ数ずつ」の乗法2問・等分除1問・包含除1問、および同じ型の作問も接続しています。乗法は一皿分から、除法は全体から図を組み立てます。「一皿分」「いくつ分」「ぜんぶ」を異なる単位とともに弧へ置き、関係を確かめて持ち帰れます。未知の皿数は図の途中を省略して隠し、図の枠を数えるだけで答えが分からないようにします。現在はボタンで図を組み立てる支援で、手描きの乗除や倍・割合・比の接続は今後の対象です。

図化教材の開発元は [tape-diagram](https://github.com/yggdrasilw-spec/tape-diagram)。`diagram/` は配布用コピーなので直接編集せず、開発元を更新・コミットした後に `node scripts/sync-diagram.cjs 開発元のローカルパス` で同期します。取り込んだコミットは `diagram/SOURCE.json` に記録します。接続部は `diagram-bridge.js`、追加検証は `npm run test:bridge`。Web配信とHTML直接起動の両方で動作し、実行時にネット接続は必要ありません。

`index.html`を開くと使える、ビルド不要の試作教材。外部ライブラリ・ネット接続・LLMは不要。6学年44問の代表問題で、立式の考え方が広がる流れを試せます。年間の全単元・全問題型を網羅する教材ではありません。

## 学習内容

|学年|問題数|今回の代表内容|児童に合わせた表現|
|---|---:|---|---|
|1年|4|合併・増加・残り・違い|ものの○、取り去る印、一対一の対応|
|2年|11|加減の逆思考、同数累加・乗法、整数倍|全体と部分のテープ、一皿ずつのまとまり|
|3年|6|等分除・包含除、何倍・基準量、二段階、小数加法|同じ数ずつ配る操作・取り分ける操作、途中の量|
|4年|5|括弧と別解、面積、小数×整数、小数の倍|色と人数でまとめる二つの道筋、単位面積の格子、対応|
|5年|10|小数倍・小数乗除、割合・百分率・値引き、平均、速さ|基準1の対応、100%のバー、ならす操作、時間と道のり|
|6年|8|分数乗除、比、比例・反比例|分数の対応、リボンの取り分け、比の一つ分、条件付きの表|

学年対応は[文部科学省・小学校学習指導要領解説 算数編](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)を基礎にしています。問題の配列・図・文言は本教材の独自案です。割合の導入の全てや、分数の全内容、時刻・時間・単位換算、図形の全内容、データなどは未収録です。

## 子どもの理解を優先する設計

共通にするのは「何を聞かれる？→式→答え→理由→確かめる」という学習の流れです。全てを同じ図や同じ意味に当てはめません。

- 等分除は、皿の数が既知で、一つずつ等しく配る。
- 包含除は、一皿分が既知で、その数ずつ取り分ける。
- 割合は、どの量が100%（1）かを確かめる。
- 比は、同じ大きさの一つ分を比の数だけ並べる。
- 平均は、合計を変えずに等しくならす。
- 比例は、単価が一定・追加料金なしなどの条件を明示する。
- 反比例は、同じ仕事・同じ速さ・分担できる条件で人数と時間を扱う。

図の操作はヒントで開いたときに行えます。配る・ならす操作は、見て数えて解くための支援なので意図的に結果を可視化します。初期の問題表示には未知の量を数値で出しません。テープは模式図で、未知の値を縮尺から読み取らせません。

## 段階と保存

現在の学年内で、既習問題と次の1問だけを選べます。式・答え・理由を確認すると次の問題が開き、その学年を終えると次の学年・作問が開きます。前後ボタンは学年をまたがず、循環もしません。復習では前の学年へ戻れます。

作問は、その学年で実際に学んだ型と質問の場所に限ります。1年生の段階には逆思考・乗除・割合の説明を混ぜません。学年内でも、新しい概念の問題へ到達するまではその問題の説明を出しません。

進捗・学習位置・最後の作問をlocalStorageキー`word-problem-lab-v3`に保存。1〜2年版の旧記録は削除せず別キーに残しています。今回の6学年版は最初から進めます。保存できない環境でも画面内の学習は使えます。

## 式と理由の判定

整数・小数・分数、四則、括弧、等号、□を扱います。`3/4`、`×`または`*`、`÷`または`/`、全角も使えます。途中の式は改行または`;`で区切ります。例：

```text
2+3=5
5*4=20
```

「一人分を先に求める」と「色ごとに求めて合わせる」の双方を認めます。同数累加と乗法、百分率と小数による立式、分数乗除、比の一つ分と割合による別解も登録しています。加法・乗法の順序や結合、等式の左右を替える表し方も扱います。

任意のJavaScriptをevalしません。式を構文木にし、登録した意味のある道筋・関係式と照合します。計算結果が同じだけの任意の式は通しません。途中の式は計算の正しさと、登録した道筋につながることを検査します。道筋が識別できた場合、選んだ理由がその道筋に合うことも確認します。

自由に発想した全ての別解を自動判定できる段階ではありません。理由は選択肢での支援付き説明で、児童が自力で説明できることを実証するものではありません。語彙・図・ヒント量は、児童と教師による試用で調整する必要があります。

## 作問

その学年の問題を終えたあと、学んだ問題の型を選び、数と質問を変更できます。小数・分数も入力可能。数や比の成立条件を検査し、分ける本数・人数・比の一つ分などが不自然にならないようにします。問題を作ったら、その問題で式・答え・理由を練習できます。

自由作文やLLMとの接続は未実装。作問は数量と文型を組み合わせる方式です。

## 構成と検証

- `engine.js`：以前からの加減の数量モデルと判定。
- `curriculum.js`：学年別の問題・概念・理由・FAQ、数式解析と複数段判定。
- `diagrams.js`：各概念に合わせた図と操作。
- `illustrations.js`：お話のものの見本と、数量に合わせて並べる画像素材。
- `assets/illustrations/`：組み込みの画像生成ツールで作った17種類の透過PNG。生成プロンプトは `prompts.json`。
- `assets/scenes/`：13種類の動作場面。合併・増加・減少・比較・同数のまとまり・等分除・包含除・カード・長さ・切り分け・平均・速さ・分担を扱います。
- `action-scenes.js`：場面と問題の対応、既知の量と聞かれた量の表示。場面はヒント内で必要なときだけ開きます。
- `interactive-guides.js`：4年の面積、5年の割合・値引き、6年の比・比例を操作して確かめる図。各学年の該当問題だけに表示します。
- `docs/visual-plan.json`：全44問で絵や図が支える概念と、聞かれた量の一覧。
- `app.js`：学習順序・入力・フィードバック・保存・作問。
- `docs/research-and-design.md`：調査と全体設計。

`node scripts/qa-word-problem-lab.cjs`で、全44問を1年から6年まで順に操作し、各学年の作問、保存、復習、リセット、複数の道筋、途中の式、割合、小数・分数、配る・取り分ける・ならす操作、スマートフォンの横はみ出しを確認します。スクリーンショットは `qa-output/` へ保存します（Gitには含めません）。

## 検証の実行方法

画像は一つの物の素材として生成し、図の個数・配り方・取り分け方はコードで制御します。見本の画像の大きさは実際の長さや割合を表しません。割合のバー、分数の区切り、面積の格子などの数量表現は、引き続き数値に基づく図を使います。低学年の加減・比較、乗除、カードの二段階問題には、数に合った画像をヒント内に並べています。

動作場面は35問に対応し、今の問題の数値を描いた絵ではないことを明示しています。場面の下には問題の実際の量を表示し、聞かれた量は□にします。食べる場面でも「はじめ」を聞く場合は、はじめの量に□を示します。等分除は皿数を決めて一つずつ配る、包含除は一皿分を決めてまとまりごとに取る、という順序を分けています。包含除の小袋は一皿分のまとまりの見本です。

残り9問の面積・割合・百分率・値引き・比・比例は、模式図・格子・対応表を中心にします。面積の格子には単位の正方形の画像を使い、平均では本の画像の合計を変えずに三日分をならします。動作の絵から個数や長さを読み取らせる目的ではありません。児童による理解度の確認は別途必要です。

この9問には「操作して、関係をたしかめる」を追加しています。割合は100%にする量を選び、一マス1%の図で確認します。割合が未知のときは、操作するまで色を付けません。比は同じ一つ分を求めてから、実際の玉を各まとまりに並べます。比例は冊数と代金を同じ列で選び、追加料金がある場合は比例しないことも説明します。面積は一列ずつ単位の正方形を数えます。ヒントの操作だけでは問題の完了・次の段階の開放にはなりません。

Node.js 20以上で、以下を実行してください。教材を使うだけならインストールは不要です。

~~~sh
npm install
npx playwright install chromium
npm test
~~~

検証するブラウザは環境変数 CHROME_EXECUTABLE、スクリーンショットの保存先は QA_OUTPUT で変更できます。
